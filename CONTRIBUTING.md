# Contributing

Pull requests are welcome.

## AI disclosure

This project is built with AI tools and says so: every commit made with one carries a
`Co-Authored-By:` line naming the tool.

The same applies to contributions. If any part of a pull request was written or generated
with an AI tool:

- say so in the pull request, and name the tool;
- add a `Co-Authored-By:` trailer naming the tool to each of those commits.

Pull requests that present AI-written work as the contributor's own will not be merged.

## What gets merged

- One change per pull request. Unrelated features go in separate pull requests.
- No game data: no disc files, carved assets or extracted media.
- Behaviour must match the original game. Cite the evidence (the decompiled function, disc
  data, or a capture from the original running in an emulator) for any rule you change.
