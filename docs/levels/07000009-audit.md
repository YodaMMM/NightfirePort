# 07000009 — the behaviour audit (`level-09-audit`, 2026-10-26)

Every placement on the main map (archive `07000009.bin`, main map = map 39, **288 placements, 23
kinds** [D `nf-extract level-survey` + `placements-all`]) against the game. Method: the disc census
is `nf-extract placements-all $NF_ISO 07000009.bin` [D]; the creator for every type is
`parsemap_create_dynamic_objects` 0x1d04f0 — a 240-entry jump table at 0x304b20 indexed by the raw
placement type word at placement+0x8, one case per type, each gated on the caller's flag
(`ResetMap_Load` 0x1d6360 passes 1 on the final load; `parsemap_parsemap` 0x1d1cf0 passes 0 on the
streaming pass — gameplay objects spawn only on the final load; caller pre-gate at 0x1d1c84 skips
types with bits 0x8000/0x2000 and skips when the celglist is NULL) [M decomp + asm cross-check of
0x1d04f0 and caller 0x1d1b68]; the port side is the matching `nf-game` module (central attach point
`Drones::attach_level_id` drone.rs:12237-12708, draw census oracle
`placement_draw_census_live.rs`). The interactable census already lived in `07000009.md` — this file
adds the full 23-kind table with the static path, the decoded scripts (all 11 NIS in the archive),
the mission record, and the GAP list. Errata against `07000009.md` are marked **ERRATA** and fixed
there by this task.
