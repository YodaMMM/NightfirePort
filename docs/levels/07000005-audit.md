Every main-map placement of 07000005 [D], one row each, against the game's own code [M] and the
port's. Method: the census probe `census_07000005.rs --ignored` re-dumped all 363 placements from
the disc (`NF_ISO` archive 07000005.bin, 51 maps, main map 50, 178 objects — the same counts the
level doc's §7 census carries); the per-kind game chains come from the decompile (work/decomp/ACTION.ELF,
creator dispatch `parsemap_create_dynamic_objects` 0x1d04f0 + each creator/updater/handler) and from
the per-kind research already merged on the 06/08 audits (docs/levels/07000006-audit.md,
07000008-audit.md — the creators are level-independent); the port side was swept through
crates/nf-game + crates/nf-view/src/scene.rs's placement loops. Tests cited are the ones that pin
the row. The eight level scripts were decoded with the `dump_sp_script` example (stream/Anim/Event
prints [D]).

Zero on this level (the §7 census's own zero list, re-checked against the dispatcher and the 363
placements [D]): switches 0x29, locks 0x2E, monitors 0x30, lifts 0x27, sensors 0x28, inverters 0x41,
