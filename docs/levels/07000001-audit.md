# 07000001 behaviour audit (level-01-audit)

The level's per-kind census lives in `docs/levels/07000001.md`; this audit adds the per-placement
rows (one row per placement of the main map 01000093 [D]), the scripts' full stream decodes, the
mission records, and the gap list. Method: the placements were re-parsed from the disc this session
(ordinal numbering — the record's own u16 object-index field is NOT the placement number; the older
census rows that say "#9-#12" for the 0xD8 props are ordinal numbers and match this dump), the
scripts decoded from 07800001.bin / the level archive with the same parser used for 07000014
([D] host-float), the game side re-cited from the decompile, and the port side re-grepped this
session. The numbering below is the placement ordinal (0-based, block order).
