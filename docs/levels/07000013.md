## 8. The security gate — solved (task 716b)

The objective's "security gate" is a REAL mechanism the earlier §7 note missed. **SimpleScript #149
"Shutters2"** (trigger ch 0x23 [D param 3]) is not the security-room shutter — its cel's glist spans
the **front-entrance mouth** (x −8.54..−4.97 at z 65.02 [D obj 65's bounds]); it is the gate panel,
and at key 0 it blocks the capsule band exactly where the walkreal route pinned (z ≈ 65).

**The writer of ch 0x23**: ScriptPlayer #161 "SCRIPTPLAYER_Elevators" (mode 64 = preload-then-prime,
mask 4 = E-usable, **out ch 0x23** [D params (5,4),(6,23)] — the old §4 "ch 0x23 has no writer" read
param 6 as a trigger; it is the OUT channel, the same map the elevator-button task used on
07000009 #70). The preload's Entity op creates 0x02000A2C "SCRIPT_SHUTTER_CLOSE" — the west-wall
panel's world-baked glist at (−18.08, −368.23, 25.01) [D obj 70; the OPEN twin 0x02000A2B replaces
it at the script's t=16] — with obj+0xE4 = the SP handle [M Script_EntityStart 0x1d8d78:110], so the
E pick's class-0 arm reaches SP_Activate [M Player_Activate 0x1a5170:121-122] and the played script
writes ch 0x23 [M SP_Update 0x1dbda8:221-229]. The panel display (SHUTTER_CLOSE → OPEN) and the
gate rise are one interaction: E the west-wall panel, the entrance gate lifts [M SS_Update
0x1a9948 + KeyFrame_Interp 0x1e1140; the posed slab's collision follows the set_dynamic pass].
